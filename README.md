## ▶️ How to run

Below are simple commands you can run from a terminal. Replace the example filenames with any file in this repository.

- JavaScript (Node.js):

```bash
# run a JS file with Node.js
node 1-two_sums.js
# or: node path/to/file.js
```

- Python:

```bash
# run a Python file (Windows/macOS/Linux)
python 1-two_sums.py
# or, if your system uses python3:
python3 1-two_sums.py
```

- C++ (compile then run):

On Windows (using MinGW / g++):

```powershell
# compile
g++ -std=c++20 -Wall -Wextra -g 1-two_sums.cpp -o 1-two_sums.exe
# run
.\1-two_sums.exe
```

On macOS / Linux:

```bash
# compile
g++ -std=c++20 -Wall -Wextra -g 1-two_sums.cpp -o 1-two_sums
# run
./1-two_sums
```

Tip: VS Code has a "Build C++ file" task configured in this workspace; use `Tasks → Run Build Task` to compile the active C++ file quickly.
